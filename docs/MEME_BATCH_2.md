## Source boundaries

`scripts/items/lets_delve.lua` calls the native shovel as a mimicked effect without an active-slot owner, additional costume, nested use animation or explicit nested wisp request. The outer active owns its discharge and animation. Car Battery's wrapper repeat is ignored. NOHUD/NOANIM requests are respected. Native callbacks still run: cross-mod reactions, Void and Book of Virtues need an engine check. The API returns no success result from UseActiveItem, so the wrapper cannot honestly refund only failed digs.

`scripts/items/six_seven.lua` uses GetPillRNG(effect), makes one draw and calls AddBlueFlies for the using player. The base Repentance MC_USE_PILL contract does not promise a pill-color argument. The same-size rule intentionally avoids inferring horse size from an optional argument or a pocket inventory that may already have changed. Placebo and Echo Chamber may invoke the effect again; each actual callback rolls again, with NOHUD honored. No native damage, familiar ownership, pocket inventory, player type, charge, save table or input override is written directly.

Existing XML entries retain their order; new entries are appended. The collectible has an original 32x32 geometric shovel-and-note placeholder, generated by `tools/make_placeholders.py` under the existing MIT placeholder terms. It contains no extracted shovel pixels or company logo. The pill retains native randomized pill artwork and distribution; a collectible pool entry or fixed custom pill-color icon would be misleading. English EID, pickup text, all three READMEs, inventory counts and generated ITEMS.md are updated.
